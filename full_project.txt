==> README.md <==
# Price Tracker

![CI](https://github.com/amirsalarhabibi/price-tracker/actions/workflows/ci.yml/badge.svg)

A small FastAPI service that records USD and gold prices and exposes their history.
Built as a DevOps portfolio project: Docker, GitHub Actions CI, and (coming next) monitoring.

## Run locally

```bash
docker compose up --build
```

Then open http://127.0.0.1:8000/docs

## Endpoints

- `GET /health`: service status
- `POST /prices/{asset}/refresh`: fetch and store the latest price (`usd`, `gold`)
- `GET /prices/{asset}/history`: stored price history

## Tests

```bash
pip install -r requirements.txt
python -m pytest
```

## Roadmap

- [x] API + SQLite storage
- [x] Dockerfile and docker-compose
- [x] CI with GitHub Actions
- [x] Real price sources (Nobitex USDT, world gold ounce)
- [ ] Telegram alerts
- [ ] Prometheus and Grafana monitoring

## How it works

- Prices are collected from several sources in parallel, each with a timeout. A failing source is skipped instead of breaking the request.
- Sources fed by the same upstream share a *group*. Confidence (`low` / `medium` / `high`) depends on the number of independent groups, not on the number of sources.
- A background task polls every 60 seconds (`POLL_INTERVAL`) and stores each result with its confidence.
- `GET /prices/{asset}/latest` returns the age of the data and a `stale` flag, so old data is never presented as fresh.
- The USD price is the USDT price on an Iranian exchange, used as a proxy. 18k gold per gram is an *estimate* derived from the world ounce price and the USD price, and is marked `estimated: true`.

## Outage behavior

`scripts/outage_test.sh` blocks the container's outgoing traffic for about two minutes (needs sudo, uses the iptables `DOCKER-USER` chain). While blocked, the API keeps serving the last stored price together with its `age_seconds`. After the block is removed, polling resumes on its own (about 20 seconds in the last run).

## Monitoring

- `GET /metrics` exposes Prometheus metrics: `price_tracker_price`, `price_tracker_price_age_seconds`, `price_tracker_groups_ok`, `price_tracker_source_up`, `price_tracker_source_last_success_timestamp_seconds`, `price_tracker_source_requests_total` and `price_tracker_source_failures_total{error=...}`.
- `GET /sources` returns the same per-source status as JSON.
- Every failure is classified (`dns`, `timeout`, `tls`, `http_error`, `connection`, `bad_response`, `other`), which makes it possible to tell a blocked source apart from one that changed its response format.
- Source counters live in memory and reset when the service restarts.

## Monitoring stack

`docker compose up --build` also starts Prometheus and Grafana (bound to localhost only).

- Grafana: http://localhost:3000 (user `admin`, password `admin` unless `GRAFANA_PASSWORD` is set). The "Price Tracker" dashboard is provisioned automatically.
- Prometheus: http://localhost:9090 (targets at `/targets`, alert rules at `/alerts`).
- Alert rules: `TrackerDown` (API cannot be scraped), `PriceStale` (price older than 15 minutes), `SourceDown` (a source failing for 3 minutes).
- A test checks that the dashboard and the alert rules only use metrics the app really exports.

## Container and API hardening

- The container runs as a non-root user and has a `HEALTHCHECK` (`docker compose ps` shows `healthy`).
- Direct dependencies are pinned in `requirements.txt`, and Dependabot proposes weekly updates for pip, Docker and GitHub Actions.
- `POST /prices/{asset}/refresh` returns the stored price (`"cached": true`) when it is younger than `REFRESH_MIN_INTERVAL` seconds (default 10), so repeated calls cannot exhaust the upstream rate limits. It is a cache, not authentication.
- The USD price is reused for 20 seconds, so the gold estimate does not query the USD source a second time.


import os
import sqlite3

DB_PATH = os.getenv("DB_PATH", "data/prices.db")

NEW_COLUMNS = (
    ("sources_ok", "INTEGER NOT NULL DEFAULT 1"),
    ("confidence", "TEXT NOT NULL DEFAULT 'low'"),
    ("groups_ok", "INTEGER NOT NULL DEFAULT 1"),
    ("estimated", "INTEGER NOT NULL DEFAULT 0"),
)


def get_conn():
    os.makedirs(os.path.dirname(DB_PATH) or ".", exist_ok=True)
    conn = sqlite3.connect(DB_PATH, timeout=10.0)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA journal_mode=WAL")
    conn.execute("PRAGMA synchronous=NORMAL")
    return conn


def init_db():
    with get_conn() as c:
        c.execute("""
            CREATE TABLE IF NOT EXISTS prices (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                asset TEXT NOT NULL,
                price REAL NOT NULL,
                created_at TEXT NOT NULL DEFAULT (datetime('now'))
            )
        """)
        cols = {r["name"] for r in c.execute("PRAGMA table_info(prices)")}
        for name, ddl in NEW_COLUMNS:
            if name not in cols:
                c.execute(f"ALTER TABLE prices ADD COLUMN {name} {ddl}")
        c.execute(
            "CREATE INDEX IF NOT EXISTS idx_prices_asset_id ON prices (asset, id DESC)"
        )

import os
import threading
import time

from app.sources import FakeSource, HttpJsonSource, collect, gold18_gram

SUPPORTED = ("usd", "gold")
USD_CACHE_TTL = 20  # seconds: the gold estimate needs the USD price right after the USD fetch

# USDT price in Iran is used as a proxy for the dollar.
# Nobitex returns rials, so its scale is 0.1 (rial -> toman).
USD_SOURCES = [
    HttpJsonSource(
        name="nobitex-usdt",
        config={
            "usd": (
                "https://apiv2.nobitex.ir/market/stats?srcCurrency=usdt&dstCurrency=rls",
                ["stats", "usdt-rls", "latest"],
            )
        },
        scale=0.1,
        group="nobitex",
        user_agent="TraderBot/PriceTracker-1.0",
    ),
    HttpJsonSource(
        name="tetherland-usdt",
        config={
            "usd": (
                "https://api.tetherland.com/currencies",
                ["data", "currencies", "USDT", "price"],
            )
        },
        scale=1.0,
        group="tetherland",
        user_agent="TraderBot/PriceTracker-1.0",
    ),
    HttpJsonSource(
        name="wallex-usdt",
        config={
            "usd": (
                "https://api.wallex.ir/v1/markets",
                ["result", "symbols", "USDTTMN", "stats", "lastPrice"],
            )
        },
        scale=1.0,
        group="wallex",
        user_agent="TraderBot/PriceTracker-1.0",
    ),
]

# World gold ounce in USD. Both seem to share one upstream, so they share one group.
OUNCE_SOURCES = [
    HttpJsonSource(
        "gold-api",
        {"xau": ("https://api.gold-api.com/price/XAU", ["price"])},
        group="gold-api",
    ),
    HttpJsonSource(
        "xaus",
        {"xau": ("https://xaus.com/api/v1/spot", ["spot_usd_oz"])},
        group="gold-api",
    ),
]

_ORDER = {"low": 0, "medium": 1, "high": 2}
_usd_cache = {"ts": 0.0, "value": None}
_usd_lock = threading.Lock()


def _usd_cached():
    with _usd_lock:
        fresh = time.time() - _usd_cache["ts"] < USD_CACHE_TTL
        if _usd_cache["value"] is not None and fresh:
            return _usd_cache["value"]
        value = collect("usd", USD_SOURCES)
        if value is not None:
            _usd_cache.update(ts=time.time(), value=value)
        return value


def _gold_estimate():
    usd = _usd_cached()
    ounce = collect("xau", OUNCE_SOURCES)
    if usd is None or ounce is None:
        return None
    return {
        "price": round(gold18_gram(ounce["price"], usd["price"])),
        "sources_ok": usd["sources_ok"] + ounce["sources_ok"],
        "sources_total": usd["sources_total"] + ounce["sources_total"],
        "groups_ok": min(usd["groups_ok"], ounce["groups_ok"]),
        "confidence": min(usd["confidence"], ounce["confidence"], key=_ORDER.get),
        "estimated": True,
    }


def fetch_price(asset: str) -> dict:
    if asset not in SUPPORTED:
        raise ValueError(f"unknown asset: {asset}")
    if os.getenv("USE_FAKE_SOURCES") == "1":
        result = collect(asset, [FakeSource()])
    elif asset == "usd":
        result = _usd_cached()
    else:
        result = _gold_estimate()
    if result is None:
        raise RuntimeError("no source available")
    return result

import asyncio
import logging
import os
import time
from contextlib import asynccontextmanager

from fastapi import FastAPI, HTTPException, Response
from prometheus_client import CONTENT_TYPE_LATEST, generate_latest

from app import db, fetcher, metrics, sources

logging.basicConfig(level=logging.INFO)
log = logging.getLogger("price-tracker")

STALE_AFTER = 900  # seconds
POLL_INTERVAL = int(os.getenv("POLL_INTERVAL", "60"))
# POST /refresh returns the stored price when it is younger than this (seconds).
REFRESH_MIN_INTERVAL = int(os.getenv("REFRESH_MIN_INTERVAL", "10"))


def refresh_asset(asset: str) -> dict:
    """Fetch one asset and store it. Raises ValueError or RuntimeError."""
    r = fetcher.fetch_price(asset)
    with db.get_conn() as c:
        c.execute(
            "INSERT INTO prices (asset, price, sources_ok, groups_ok, confidence, estimated) "
            "VALUES (?, ?, ?, ?, ?, ?)",
            (asset, r["price"], r["sources_ok"], r["groups_ok"],
             r["confidence"], int(r.get("estimated", False))),
        )
    return r


def _latest_row(asset: str):
    with db.get_conn() as c:
        return c.execute(
            "SELECT price, sources_ok, groups_ok, confidence, estimated, "
            "CAST(strftime('%s','now') - strftime('%s', created_at) AS INTEGER) AS age_seconds "
            "FROM prices WHERE asset=? ORDER BY id DESC LIMIT 1",
            (asset,),
        ).fetchone()


async def poll_forever():
    while True:
        for asset in fetcher.SUPPORTED:
            try:
                r = await asyncio.to_thread(refresh_asset, asset)
                log.info("poll %s ok: %s (%s)", asset, r["price"], r["confidence"])
            except Exception as e:  # noqa: BLE001  # one failure must not stop the loop
                log.warning("poll %s failed: %s", asset, e)
        await asyncio.sleep(POLL_INTERVAL)


@asynccontextmanager
async def lifespan(app: FastAPI):
    db.init_db()
    task = None
    if os.getenv("DISABLE_POLLER") != "1":
        task = asyncio.create_task(poll_forever())
    yield
    if task:
        task.cancel()


app = FastAPI(title="Price Tracker", lifespan=lifespan)


@app.get("/health")
def health():
    return {"status": "ok"}


@app.post("/prices/{asset}/refresh")
def refresh(asset: str):
    if asset not in fetcher.SUPPORTED:
        raise HTTPException(status_code=404, detail="unknown asset")
    row = _latest_row(asset)
    if row is not None and row["age_seconds"] < REFRESH_MIN_INTERVAL:
        return {
            "asset": asset,
            "price": row["price"],
            "sources_ok": row["sources_ok"],
            "groups_ok": row["groups_ok"],
            "confidence": row["confidence"],
            "estimated": bool(row["estimated"]),
            "cached": True,
            "age_seconds": row["age_seconds"],
        }
    try:
        r = refresh_asset(asset)
    except ValueError:
        raise HTTPException(status_code=404, detail="unknown asset")
    except RuntimeError:
        raise HTTPException(status_code=503, detail="no source available")
    return {"asset": asset, **r, "cached": False}


@app.get("/prices/{asset}/latest")
def latest(asset: str):
    with db.get_conn() as c:
        row = c.execute(
            "SELECT price, sources_ok, groups_ok, confidence, estimated, created_at, "
            "CAST(strftime('%s','now') - strftime('%s', created_at) AS INTEGER) AS age_seconds "
            "FROM prices WHERE asset=? ORDER BY id DESC LIMIT 1",
            (asset,),
        ).fetchone()
    if row is None:
        raise HTTPException(status_code=404, detail="no data yet")
    data = dict(row)
    data["estimated"] = bool(data["estimated"])
    data["stale"] = data["age_seconds"] > STALE_AFTER
    return data


@app.get("/prices/{asset}/history")
def history(asset: str, limit: int = 50):
    with db.get_conn() as c:
        rows = c.execute(
            "SELECT price, sources_ok, groups_ok, confidence, estimated, created_at "
            "FROM prices WHERE asset=? ORDER BY id DESC LIMIT ?",
            (asset, limit),
        ).fetchall()
    return [{**dict(r), "estimated": bool(r["estimated"])} for r in rows]


@app.get("/sources")
def sources_status():
    now = time.time()
    out = {}
    for name, s in sources.snapshot().items():
        ts = s["last_success_ts"]
        out[name] = {**s, "last_success_age_seconds": None if ts is None else int(now - ts)}
    return out


@app.get("/metrics")
def metrics_endpoint():
    return Response(generate_latest(metrics.REGISTRY), media_type=CONTENT_TYPE_LATEST)

from prometheus_client import CollectorRegistry
from prometheus_client.core import CounterMetricFamily, GaugeMetricFamily

from app import db, sources

REGISTRY = CollectorRegistry()


class TrackerCollector:
    """Builds the metrics when Prometheus scrapes, from the source stats and the database."""

    def collect(self):
        snap = sources.snapshot()

        up = GaugeMetricFamily(
            "price_tracker_source_up", "1 if the last attempt on this source worked", labels=["source"]
        )
        last_ok = GaugeMetricFamily(
            "price_tracker_source_last_success_timestamp_seconds",
            "Unix time of the last successful fetch",
            labels=["source"],
        )
        attempts = CounterMetricFamily(
            "price_tracker_source_requests", "Fetch attempts per source", labels=["source"]
        )
        failures = CounterMetricFamily(
            "price_tracker_source_failures",
            "Failed fetches per source and error type",
            labels=["source", "error"],
        )
        for name, s in snap.items():
            if s["up"] is not None:
                up.add_metric([name], 1 if s["up"] else 0)
            if s["last_success_ts"] is not None:
                last_ok.add_metric([name], s["last_success_ts"])
            attempts.add_metric([name], s["attempts"])
            for err, n in s["failures"].items():
                failures.add_metric([name, err], n)
        yield up
        yield last_ok
        yield attempts
        yield failures

        circuit = GaugeMetricFamily(
            "price_tracker_source_circuit_open",
            "1 if the circuit breaker is open (source quarantined)",
            labels=["source"],
        )
        outliers = CounterMetricFamily(
            "price_tracker_source_outliers",
            "Times this source was dropped for being far from the other sources",
            labels=["source"],
        )
        for name, s in snap.items():
            circuit.add_metric([name], 1 if s.get("circuit") == "open" else 0)
            outliers.add_metric([name], s.get("outliers", 0))
        yield circuit
        yield outliers

        price = GaugeMetricFamily(
            "price_tracker_price", "Latest stored price (toman)", labels=["asset"]
        )
        age = GaugeMetricFamily(
            "price_tracker_price_age_seconds", "Age of the latest stored price", labels=["asset"]
        )
        groups = GaugeMetricFamily(
            "price_tracker_groups_ok", "Independent source groups behind the latest price", labels=["asset"]
        )
        try:
            with db.get_conn() as c:
                rows = c.execute(
                    "SELECT asset, price, groups_ok, "
                    "CAST(strftime('%s','now') - strftime('%s', created_at) AS INTEGER) AS age "
                    "FROM prices WHERE id IN (SELECT MAX(id) FROM prices GROUP BY asset)"
                ).fetchall()
        except Exception:  # noqa: BLE001
            rows = []
        for r in rows:
            price.add_metric([r["asset"]], r["price"])
            age.add_metric([r["asset"]], r["age"])
            groups.add_metric([r["asset"]], r["groups_ok"])
        yield price
        yield age
        yield groups


REGISTRY.register(TrackerCollector())

==> app/sources.py <==
import json
import os
import random
import socket
import ssl
import statistics
import threading
import time
import typing
import urllib.error
import urllib.request
from concurrent.futures import ThreadPoolExecutor

TIMEOUT = float(os.getenv("SOURCE_TIMEOUT", "5"))
CB_FAIL_THRESHOLD = int(os.getenv("CB_FAIL_THRESHOLD", "3"))
CB_COOLDOWN_SEC = float(os.getenv("CB_COOLDOWN_SEC", "60"))
OUTLIER_PCT = float(os.getenv("OUTLIER_PCT", "5"))

_lock = threading.Lock()
_stats = {}


def classify_error(exc: Exception) -> str:
    """Name the kind of failure, so a blocked source can be told apart from a broken one."""
    if isinstance(exc, urllib.error.HTTPError):
        return "http_error"
    if isinstance(exc, urllib.error.URLError):
        reason = exc.reason
        if isinstance(reason, socket.gaierror):
            return "dns"
        if isinstance(reason, TimeoutError):
            return "timeout"
        if isinstance(reason, ssl.SSLError):
            return "tls"
        return "connection"
    if isinstance(exc, TimeoutError):
        return "timeout"
    if isinstance(exc, ssl.SSLError):
        return "tls"
    if isinstance(exc, (ValueError, KeyError, TypeError, IndexError)):
        return "bad_response"
    if isinstance(exc, OSError):
        return "connection"
    return "other"


def _entry(source):
    return _stats.setdefault(
        source.name,
        {
            "group": source.group_id(),
            "attempts": 0,
            "failures": {},
            "up": None,
            "last_success_ts": None,
            "last_error": None,
            "consecutive_failures": 0,
            "circuit": "closed",
            "cooldown_until": None,
        },
    )


def is_circuit_open(source) -> bool:
    """Check if the source is temporarily quarantined by the Circuit Breaker."""
    with _lock:
        e = _entry(source)
        if e["circuit"] == "open":
            if e["cooldown_until"] and time.time() >= e["cooldown_until"]:
                e["circuit"] = "half-open"
                return False
            return True
        return False


def record_success(source):
    with _lock:
        e = _entry(source)
        e["attempts"] += 1
        e["up"] = True
        e["last_success_ts"] = time.time()
        e["consecutive_failures"] = 0
        e["circuit"] = "closed"
        e["cooldown_until"] = None


def record_failure(source, exc: Exception):
    kind = classify_error(exc)
    with _lock:
        e = _entry(source)
        e["attempts"] += 1
        e["up"] = False
        e["last_error"] = kind
        e["failures"][kind] = e["failures"].get(kind, 0) + 1
        e["consecutive_failures"] += 1
        if e["consecutive_failures"] >= CB_FAIL_THRESHOLD:
            e["circuit"] = "open"
            e["cooldown_until"] = time.time() + CB_COOLDOWN_SEC


def snapshot() -> dict:
    with _lock:
        return {n: {**e, "failures": dict(e["failures"])} for n, e in _stats.items()}


def reset_stats():
    with _lock:
        _stats.clear()


class Source:
    name = "base"
    group = None  # sources fed by the same upstream share a group

    def group_id(self) -> str:
        return self.group or self.name

    def fetch(self, asset: str) -> float:
        raise NotImplementedError


class FakeSource(Source):
    name = "fake"
    BASE: typing.ClassVar[dict[str, float]] = {"usd": 60000, "gold": 3000000, "xau": 4000}

    def fetch(self, asset: str) -> float:
        return self.BASE[asset] * random.uniform(0.98, 1.02)


class HttpJsonSource(Source):
    def __init__(self, name, config, scale=1.0, group=None, user_agent="Mozilla/5.0"):
        self.name = name
        self.config = config
        self.scale = scale
        self.group = group
        self.user_agent = user_agent

    def fetch(self, asset: str) -> float:
        url, path = self.config[asset]
        req = urllib.request.Request(url, headers={"User-Agent": self.user_agent})
        with urllib.request.urlopen(req, timeout=TIMEOUT) as resp:
            data = json.load(resp)
        for key in path:
            data = data[key]
        val = float(str(data).replace(",", "")) * self.scale
        if val <= 0:
            raise ValueError("non-positive price")
        return val


def confidence_for(groups_ok: int) -> str:
    if groups_ok >= 3:
        return "high"
    if groups_ok == 2:
        return "medium"
    return "low"


def record_outlier(source):
    with _lock:
        e = _entry(source)
        e["outliers"] = e.get("outliers", 0) + 1


def _spread_pct(a: float, b: float) -> float:
    return abs(a - b) / ((a + b) / 2) * 100


def collect(asset: str, sources: list):
    """Ask every source in parallel with Circuit Breaker protection.

    Median inside each group first, then median across groups, so several
    sources sharing one upstream count as one vote. With three or more groups,
    a group far from the median of all groups is dropped as an outlier.
    """

    def one(source):
        if is_circuit_open(source):
            return None
        try:
            price = float(source.fetch(asset))
        except Exception as exc:  # noqa: BLE001
            record_failure(source, exc)
            return None
        record_success(source)
        return price

    if not sources:
        return None
    with ThreadPoolExecutor(max_workers=len(sources)) as pool:
        results = list(pool.map(one, sources))

    by_group = {}  # group id -> [(source, price), ...]
    for source, price in zip(sources, results):
        if price is not None:
            by_group.setdefault(source.group_id(), []).append((source, price))
    if not by_group:
        return None

    group_price = {g: statistics.median(p for _, p in v) for g, v in by_group.items()}
    outliers = 0
    if len(group_price) >= 3:
        mid = statistics.median(group_price.values())
        for g in list(group_price):
            if abs(group_price[g] - mid) / mid * 100 > OUTLIER_PCT:
                for source, _ in by_group[g]:
                    record_outlier(source)
                del group_price[g]
                del by_group[g]
                outliers += 1

    confidence = confidence_for(len(group_price))
    if len(group_price) == 2:
        a, b = group_price.values()
        if _spread_pct(a, b) > OUTLIER_PCT:
            confidence = "low"  # two sources that disagree: we cannot tell which is right

    return {
        "price": round(statistics.median(group_price.values()), 2),
        "sources_ok": sum(len(v) for v in by_group.values()),
        "sources_total": len(sources),
        "groups_ok": len(group_price),
        "confidence": confidence,
        "outliers": outliers,
    }


def gold18_gram(ounce_usd: float, usd_price: float) -> float:
    """Estimate 18k gold per gram from the world ounce price and the USD price.
    It is an estimate: it has no local market premium."""
    return ounce_usd / 31.1035 * 0.75 * usd_price

#!/usr/bin/env bash
# Simulates an upstream outage by dropping the container's outgoing traffic only.
# The host network and Docker's own network are not touched.
set -u
get() { docker compose exec -T api python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8000/prices/usd/latest').read().decode())"; }
age() { docker compose exec -T api python -c "import urllib.request,json; print(json.load(urllib.request.urlopen('http://127.0.0.1:8000/prices/usd/latest'))['age_seconds'])" 2>/dev/null; }
sudo -v
trap 'sudo iptables -D DOCKER-USER -j DROP 2>/dev/null' EXIT
echo "--- ip_forward = $(cat /proc/sys/net/ipv4/ip_forward)  (should be 1)"
docker compose up -d
echo "--- waiting 70s for the first prices"; sleep 70
echo "--- BEFORE outage:"; get
sudo iptables -I DOCKER-USER -j DROP || { echo "could not add the block rule"; docker compose down; exit 1; }
echo "--- outage ON (container cannot reach the internet), waiting 130s"; sleep 130
echo "--- DURING outage:"; get
echo "--- from host (should still work):"; curl -s --max-time 5 localhost:8000/health || echo "localhost:8000 not reachable"; echo
sudo iptables -D DOCKER-USER -j DROP
echo "--- outage OFF, waiting for recovery (up to 150s)"
r=0; ok=0
while [ $r -lt 150 ]; do
  a=$(age)
  if [ -n "$a" ] && [ "$a" -lt 90 ]; then ok=1; break; fi
  r=$((r+10)); sleep 10
done
if [ $ok -eq 1 ]; then echo "--- RECOVERED after about ${r}s"; else echo "--- NOT recovered after ${r}s"; fi
get
echo "--- last logs:"; docker compose logs --tail 10 api
if [ $ok -eq 0 ]; then
  echo "--- DNS inside container:"
  docker compose exec -T api python -c "import socket; print(socket.gethostbyname('api.gold-api.com'))" 2>&1 | tail -1
  echo "--- HTTPS inside container:"
  docker compose exec -T api python -c "import urllib.request; print(urllib.request.urlopen('https://api.gold-api.com/price/XAU', timeout=6).status)" 2>&1 | tail -1
fi
docker compose down

import time

from app import sources
from app.sources import Source, collect


class Flaky(Source):
    name = "flaky"

    def __init__(self):
        self.fail = True
        self.calls = 0

    def fetch(self, asset):
        self.calls += 1
        if self.fail:
            raise TimeoutError("down")
        return 100.0


def _setup(monkeypatch):
    monkeypatch.setattr(sources, "CB_FAIL_THRESHOLD", 3)
    monkeypatch.setattr(sources, "CB_COOLDOWN_SEC", 0.3)
    sources.reset_stats()


def test_circuit_opens_after_threshold(monkeypatch):
    _setup(monkeypatch)
    s = Flaky()
    for _ in range(6):
        collect("usd", [s])
    assert s.calls == 3  # the open circuit stopped further calls
    assert sources.snapshot()["flaky"]["circuit"] == "open"


def test_circuit_recovers_after_cooldown(monkeypatch):
    _setup(monkeypatch)
    s = Flaky()
    for _ in range(3):
        collect("usd", [s])
    time.sleep(0.4)
    s.fail = False
    assert collect("usd", [s])["price"] == 100.0
    assert sources.snapshot()["flaky"]["circuit"] == "closed"


def test_failed_trial_reopens_circuit(monkeypatch):
    _setup(monkeypatch)
    s = Flaky()
    for _ in range(3):
        collect("usd", [s])
    time.sleep(0.4)
    before = s.calls
    collect("usd", [s])  # one trial call in the half-open state, it fails
    assert s.calls == before + 1
    assert sources.snapshot()["flaky"]["circuit"] == "open"
    collect("usd", [s])  # blocked again, no new call
    assert s.calls == before + 1

from app.sources import Source, collect, gold18_gram


class Ok(Source):
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def fetch(self, asset):
        return self.price

    name = "bad"

    def fetch(self, asset):
        raise TimeoutError("down")


class Grp(Ok):
    def __init__(self, name, price, group):
        super().__init__(name, price)
        self.group = group


def test_median_ignores_outlier():
    r = collect("usd", [Ok("a", 100), Ok("b", 102), Ok("c", 500)])
    assert r["price"] == 101.0  # 500 is dropped, median of 100 and 102
    assert r["confidence"] == "medium"


def test_failed_source_is_skipped():
    r = collect("usd", [Ok("a", 100), Bad()])
    assert r["sources_ok"] == 1
    assert r["sources_total"] == 2
    assert r["confidence"] == "low"


def test_two_sources_medium():
    r = collect("usd", [Ok("a", 100), Ok("b", 102), Bad()])
    assert r["price"] == 101.0
    assert r["confidence"] == "medium"


def test_all_fail_returns_none():
    assert collect("usd", [Bad(), Bad()]) is None


def test_gold18_formula():
    assert round(gold18_gram(31.1035, 100000)) == 75000

    assert r["sources_ok"] == 2
    assert r["groups_ok"] == 1
